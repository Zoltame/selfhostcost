# SelfHostCost

A programmatic-SEO micro-site that prices commercial SaaS against its self-hosted
open-source alternatives, per tool and per team size. Static HTML generated by Python,
served free from GitHub Pages.

Live: https://zoltame.github.io/selfhostcost/

## How it works

- `data/` holds the facts: vendor prices with the date they were read, hosting plans,
  tool sizing models, and GitHub metadata.
- `scripts/lib/model.py` turns those facts into a sizing, a server choice and a 36-month
  cost for both sides, including maintenance time.
- `scripts/build.py` renders every page into `docs/`. Comparisons whose vendor price has
  not been read from the vendor's own page are withheld, never estimated.

## Commands

```bash
pip install jinja2
python scripts/build.py              # generate the site
python scripts/check_staleness.py    # audit price and data freshness
python scripts/enrich_github.py      # refresh GitHub facts
python scripts/velocity.py --report  # 30/60-day experiment tracking
```

Operations, monetisation switches and the decision gates are in `ops/RUNBOOK.md`.
