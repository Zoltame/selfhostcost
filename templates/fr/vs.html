Ce que vous perdez, sans détour

  • La disponibilité devient votre affaire. {{ saas.name }} a une équipe d'astreinte. En auto-hébergement, une mise à jour ratée un vendredi à 18 h, c'est votre soirée.
  • Une sauvegarde n'existe que si vous avez testé sa restauration. La ligne de {{ money(ref.backup_usd_month) }} ci-dessus achète des snapshots, pas une reprise répétée.
  • {{ tool.name }} est {% if tool.difficulty == 'easy' %}léger : un seul conteneur, et rien à planifier au-delà des mises à jour d'image{% elif tool.difficulty == 'medium' %}une pile multi-conteneurs avec une base de données à sauvegarder vous-même{% else %}lourd à exploiter : plusieurs services avec état et une montée de version qui peut perdre des données si vous la bâclez{% endif %}. C'est pourquoi la ligne de maintenance est de {{ hours(ref.maintenance_hours_month) }} {{ 'heure' if ref.maintenance_hours_month < 2 else 'heures' }} par mois et non de zéro.
