What you give up, stated plainly

  • Uptime is now yours. {{ saas.name }} has an operations team on call. Self-hosted, a failed upgrade at 18:00 on a Friday is your evening.
  • Backups only exist if you test restoring them. The {{ money(ref.backup_usd_month) }} line above buys snapshots, not a rehearsed recovery.
  • {{ tool.name }} is {% if tool.difficulty == 'easy' %}a light lift: one container and no scheduled work beyond image updates{% elif tool.difficulty == 'medium' %}a multi-container stack with a database you have to back up yourself{% else %}operationally heavy: several stateful services and an upgrade path that can lose data if you rush it{% endif %}. That is why the maintenance line is {{ ref.maintenance_hours_month }} hours a month rather than zero.
