How {{ gb(sizing.ram_gb) }} was arrived at

{{ gb(tool.base_ram_gb) }} covers the stack at rest, every container the project ships included. {{ size.users }} {{ 'user' if size.users == 1 else 'users' }} at {{ tool.ram_per_user_mb }} MB each adds {{ gb(per_user_ram_gb) }}, giving {{ gb(sizing.raw_ram_gb) }}. Adding {{ (sizing.headroom_ratio * 100) | round | int }}% headroom so the machine is not run at its ceiling gives {{ gb(sizing.ram_gb) }}, and the smallest plan at or above that is the {{ plan.plan.name }} with {{ gb(plan.plan.ram_gb) }}.

Disk works the same way: {{ gb(tool.base_disk_gb) }} to begin with, plus {{ tool.disk_per_user_gb }} GB per user, so {{ gb(sizing.disk_gb) }} against the {{ gb(plan.plan.disk_gb) }} the plan includes. {% if tool.disk_per_user_gb >= 5 %} This tool is storage-hungry per user, so disk rather than memory is what will force your next upgrade. {% endif %}
