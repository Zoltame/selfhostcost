El modelo de dimensionamiento de {{ tool.name }}

{{ tool.sizing_note }}

  • {{ gb(tool.base_ram_gb) }} de memoria para todo el stack en reposo, con todos los contenedores que incluye el proyecto.
  • {{ number(tool.ram_per_user_mb) }} MB más por usuario activo, y después un {{ (headroom * 100) | round | int }} % extra para que la máquina no trabaje al límite.
  • {{ gb(tool.base_disk_gb) }} de disco para empezar, y {{ loc.compact(tool.disk_per_user_gb) }} GB más por usuario.
  • {{ tool.base_vcpu }} vCPU. Se toma de la base del proyecto y no se escala con el tamaño del equipo, porque con esta carga lo primero que se agota es la memoria.
