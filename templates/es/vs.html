A qué renuncias, sin rodeos

  • La disponibilidad pasa a ser cosa tuya. {{ saas.name }} tiene un equipo de guardia. Si autoalojas, una actualización fallida un viernes a las 18:00 es tu tarde.
  • Las copias de seguridad solo existen si has probado a restaurarlas. La línea de {{ money(ref.backup_usd_month) }} de arriba compra snapshots, no una recuperación ensayada.
  • {{ tool.name }} es {% if tool.difficulty == 'easy' %}ligero: un solo contenedor y nada que programar aparte de actualizar la imagen{% elif tool.difficulty == 'medium' %}un stack de varios contenedores con una base de datos que tienes que respaldar tú{% else %}exigente de operar: varios servicios con estado y una ruta de actualización que puede perder datos si vas con prisa{% endif %}. Por eso la línea de mantenimiento es de {{ hours(ref.maintenance_hours_month) }} horas al mes y no de cero.
