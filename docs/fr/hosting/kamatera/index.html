Points forts et points faibles

Points fortsPoints faibles
  • Son offre à 1 Go est le serveur 1 Go le moins cher parmi les hébergeurs que nous avons chiffrés
  • Les offres fixes utilisent des threads CPU dédiés, selon la page tarifaire
  • Facturation à la minute, pratique pour des essais courts
  • Chaque offre fixe n'inclut que 20 Go de disque : la plupart des outils multi-conteneurs demandent du stockage supplémentaire payant
  • Au-delà de 1 Go de mémoire, les offres fixes coûtent plus cher que DigitalOcean pour la même RAM

Offres mensuelles fixes, facturées à la minute. La page tarifaire indique le trafic supplémentaire à 0,01 $ par Go et le stockage supplémentaire à 0,05 $ par Go par mois ; aucun des deux n'est inclus dans les chiffres de ce site.
