n8n 204 061 étoiles

La valeur de base couvre un seul processus principal avec SQLite. Un gros volume de workflows demande PostgreSQL et le mode file d'attente avec des workers séparés, ce qui double à peu près le plancher.

Pour 10 personnes, il lui faut 1,5 Go de mémoire et 11 Go de disque, ce qui tient sur l'offre CX23 (cost-optimized) chez Hetzner Cloud pour 5,99 € par mois. Sa mise en place demande environ 6 heures, puis 1,5 heure par mois d'entretien. Licence : Code source disponible sous la Sustainable Use License, et non une licence open source classique.
